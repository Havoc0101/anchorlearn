## 如何运行

将源码包解压到独立目录，不覆盖 B 的现有文件。在包含 mobile-preview/ 的目录中运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory mobile-preview
```

打开 http://127.0.0.1:8766/ ，进入“我的 → 三项任务示例 → 待确认”。修改一项名称和日期，核对后保存，再刷新检查。8766 用于独立静态预览，避免占用 B 的 8765；此方式不提供分析/保存 API。

运行测试（需已有 Node，无需 npm install）：

```sh
node --test mobile-preview/integration/review.test.cjs mobile-preview/tests/model.test.cjs
```
