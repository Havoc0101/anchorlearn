## v3.2 阅读高亮

默认“主谓宾 · 少量”：蓝色主语、紫色谓语、绿色宾语。每处连续高亮 1–5 个可见字符，每句最多 3 处、最多 25% 的正文字符；宁可少标，不强行凑齐主谓宾。摘要、要点、原文和任务原话依据共用规则，支持关闭高亮；旧版“简洁重点”仍可切换。

程序防止超长、错位、相邻色块绕过限制和部分否定丢失；它不能保证 AI 理解正确。最新 v3.2 真实模型语义效果仍待课堂片段试读，不能宣称已验证适合所有 ADHD 用户。

## B 如何运行

1. 下载本交接目录或随附 ZIP 到独立目录，不覆盖正在使用的 B 工程。进入包含 `backend`、`mobile-preview` 的本包根目录。
2. 准备项目本地 `.venv`。本次验证为 macOS arm64 / Python 3.12；依赖版本见 `backend/requirements-audio.lock.txt`，直接依赖是 `faster-whisper==1.2.1`。安装前遵守自己的依赖审批规则；采用本项目 Socket Firewall 流程时，使用 `sfw .venv/bin/python -m pip install --only-binary=:all: -r backend/requirements-audio.lock.txt`。其他系统尚未验证，不全局安装。
3. 将 `backend/audio-model.json` 列出的四个模型文件放到 `backend/models/small/`，逐一核对 SHA256。约 486 MB 模型不包含在源码包内；已有相同版本模型可以复制并校验。
4. 在本包根目录启动：

```sh
.venv/bin/python backend/server.py --port 8765 --db output/local/tasks.db
```

若端口被占用，请改用 `--port 8768` 并打开相应地址。打开 `http://127.0.0.1:8765/#recording` 测试业务，`http://127.0.0.1:8765/landing.html` 查看产品页。不要直接双击 HTML 测试后端。

5. 在页面填写自己的 DeepSeek 官方 Key 并“验证并连接”。Key 仅保存在后端内存，重启需重新填写。选音频 → 转写 → 校对文字 → 提炼 → 核对任务 → 确认保存 → 日程页重新读取。仅粘贴文字分析无需语音模型；纯页面预览不需要 Key。

## 当前边界与后续

- 录音限 25 MB / 10 分钟，文字与说明合计最多 12000 字；一两小时课程的分段转写、队列进度、断点恢复和合并还没有实现。
- 真实任务确认/读取已接 SQLite；示例日程保存在浏览器，与真实任务流程区分。系统通知、系统日历、完整任务改期/取消联动未完成。
- 未接真实录音硬件 SDK、说话人识别或浏览器麦克风录音。3D 模型是外观概念展示，非官方工程文件。
- 本地服务不作为公网生产服务。打包前没有调用付费模型或使用个人录音重测；本次自动测试不代表语音准确率或真实手机体验。
- 建议 B 先独立跑通此包，再按接口和测试逐项选取改动；不要直接把整个 `backend` 覆盖到 B 最新分支上。
