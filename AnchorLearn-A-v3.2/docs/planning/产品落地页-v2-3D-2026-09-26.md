# AnchorLearn 锚学社 · 第二版产品落地页

根据用户提供的 CLOUD 家具海报，重新设计为暖灰单色、充足留白、大尺寸浅色衬线字、悬浮产品与毛玻璃分层卡片。产品文案为「锚定终身学习」「录音豆，锚定每个声音。」暂时撤下未定稿的三款 IP 外壳。

## 实现

- `mobile-preview/landing.html`、`landing.css`、`landing.js`：独立落地页，沿用已有本地服务入口。
- 原生 WebGL 创建有正面、侧面、背夹、拾音孔、指示灯和独立按键的裸机几何模型；支持拖动、方向键、Home 复位及空格按压演示。
- 视角和按键使用弹簧阻尼；页面按钮按压后回弹；卡片悬浮时轻微上移并扩散阴影。尊重减少动态效果偏好。
- WebGL 不可用或上下文丢失时显示内联 SVG 静态示意，并禁用不适用的控制。实测修复了 SVG 的 hidden 属性移除问题。
- 四步使用演示和真实产品 iframe 保留，示例数据不会提交；产品入口进入现有音频整理流程。
- 第一版归档在 `output/landing-v1-archive/`；原外壳图片仍保留，新版三文件不再引用。

模型参考 [soundcore 官方产品图](https://cdn.shopify.com/s/files/1/0501/7678/6607/files/D3200Z11_listing_image_05_US_V1_3840x.jpg?v=1761729857) 中的裸机外形，不是厂家 CAD、尺寸或制造模型；网页按压不会开始真实录音。小红书链接未能直接读取，视觉风格依据用户附图。

## 预览

<http://127.0.0.1:8770/landing.html>

仓库根目录启动命令：

```sh
.venv/bin/python backend/server.py --port 8770 --db output/local/landing-preview.db
```

此服务只监听本机。8770 使用独立预览数据库，原 8765 服务不受影响；真实分析仍需要产品页面内连接模型服务。

## 验证

```sh
node --check mobile-preview/landing.js
node --test mobile-preview/tests/model.test.cjs mobile-preview/integration/reading.test.cjs mobile-preview/integration/audio.test.cjs
git diff --check
```

17 项现有产品的数据、阅读及音频测试通过。这些测试不替代 3D 的视觉验收。另以 Python 标准库检查落地页 ID、锚点和本地资源引用。

Chrome 实际操作：桌面首屏、拖动到侧面和背面、复位、方向键与空格按压；使用演示切换到核对与保存、点击「再看一遍」回到第一步；主按钮打开真实音频选择和转文字弹窗，没有上传文件或调用分析。

Chrome 390×844、320×844 模拟视口实际显示 `renderer: webgl`，页面宽度与视口一致，无横向溢出；检查小屏首屏与使用步骤排版。通过 `WEBGL_lose_context` 实际触发渲染中断，备用示意与提示正常，刷新恢复 3D。观察到的控制台未出现脚本错误。

未进行真机触控、Safari/Firefox 或系统减少动态效果设置测试；未重跑后端/模型测试，因本次未修改后端与产品业务逻辑。没有安装依赖、运行不存在的构建命令，未上传或公开发布。
