# 接着学产品落地页

用户要求：把产品介绍与现有产品合在一个网页版入口，以最终三款手机背挂外壳作为首屏滑动换装展示，并用可视化步骤介绍怎么使用。

## 已实现

- `/landing.html`：产品介绍与现有 Web 产品入口。
- 括号猫、问号狗、感叹号狐三款切换；支持左右按钮、款式按钮、鼠标/触摸拖动、左右方向键、触控板横滑。纵向滚动仍用于浏览页面，不自动切换款式。
- 四步虚构内容演示：选音频、看重点、核对任务、确认后保存的结果。演示不提交数据，也不声称已保存。
- 嵌入现有 `index.html#home`，可打开真实录音便签；链接进入 `index.html#recording`。
- 外壳概念、真实硬件同步待接入、用户确认和数据路径的说明。
- 桌面与窄屏样式、键盘焦点、隐藏非当前轮播内容、减少动态效果样式。
