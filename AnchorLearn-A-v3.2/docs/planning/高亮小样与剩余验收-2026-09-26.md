依据根目录 `AnchorLearn-开发分工清单.md` 第 3 节确定终点，而不是以页面数量判断完成。

1. **真实文字分析验收**：配置本机 DeepSeek，真实文字产生任务和原话；编辑、确认保存、刷新后记录一致。已有核对保存代码，真实模型链路尚需验收。
2. **真实录音验收**：第一段自录音频上传、回听、实际转写和提取 3 项任务，集中核对后保存。已有录音入口和后端代码，不等于真实链路已成功。
3. **建议日程与应用内提醒**：保存后生成可调整的按天安排与提醒记录；在应用打开期间实际触发一次提醒，演示时钟需标明。当前后端路由未见独立排程和提醒能力，不能把静态卡片算完成。
4. **延期更新**：第二段录音关联正确的已有任务；展示原安排、新安排、原话；确认前不改，确认后保留原任务 ID，并同步日程和旧提醒失效状态。当前完整链路尚未验收。
5. **整条流程复演**：检查无明确期限、归属不明、重复确认和请求失败；两台演示电脑能按同一说明启动。

可以后做：全文自动语法高亮、手机锁屏通知、设备 SDK 自动同步、更多页面装饰。
