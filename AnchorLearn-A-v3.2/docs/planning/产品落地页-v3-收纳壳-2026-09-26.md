# AnchorLearn 落地页第三版：收纳壳与原版软件指南

## 用户本次要求与实现

首屏依据用户提供的官方收纳壳参考截图补建 3D 收纳组合：录音豆位于壳体右上圆形槽中，壳体保留圆角、侧面厚度、提环、接缝与接口示意。进入页面缓慢往复旋转，光源和高光随时间缓慢变化；点击组合或「取出录音豆」后，壳体移到左侧，录音豆放大到中间，可以拖动旋转、方向键调整、点按或空格体验回弹。可收回、复位，并可暂停自动旋转。窄屏分离后缩小左侧壳体以保持豆子无遮挡。

这仍是依据官方产品外形参考自行制作的网页模型，不是官方提供的 CAD，也不代表制造尺寸精度。用户的未定稿 IP 外壳不加入当前页面。

底板改为纯白 `#ffffff`，其余色调收敛到冷灰与银白，保留磨砂玻璃卡片、层次、留白与柔和阴影。

五步使用指南用同源 iframe 展示原版软件，不重新设计或着色产品界面。选择步骤只调用已有导航和打开窗口操作，保持当前表单输入，不自动填表、上传、分析或保存：

1. 我的录音：介绍「上传录音，开始整理」与文字入口。
2. 原版音频整理窗口：说明转写、校对文字及录音日期，再提炼重点与任务。
3. 内容页：原来的黄色便签、黄点展开、角色与三个页签。
4. 待确认页：说明核对日期、要求及原话，用户自己决定保存。
5. 日程页：解释查看已确认任务；没有保存过时如实展示空状态。

新增后续规划：情绪感知（线索由用户确认）、继续探索 ADHD 友好学习方式、录音遇到危险时主动一键向预设家人求助。明确标注未上线方向及求助目前不能发送，不渲染成可用的紧急按钮，不承诺自动判断危险或送达。
