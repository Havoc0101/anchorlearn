# HAVOC 9.27 本地整合版

基于 A v3.2，加入 API 切换、自定义 HTTPS OpenAI 兼容服务（需支持 /models）、简洁阅读、飞书 docx 正文导入。
文字与补充说明合计最多10万字；模型上下文不足仍会拒绝请求。每次最多提取3项任务，并不保证完整覆盖长文待办。
录音文件上限8 GB、3小时；分块接收至临时文件，每30分钟转写一段。处理结束删除临时文件，需要充足磁盘空间。无断点续传、无进度百分比；长录音速度和分段边界准确率尚未实测。
飞书妙记需先导出为已授权 docx 文档，当前不直接同步妙记或硬件。

## 启动

进入 AnchorLearn-A-v3.2 目录：

```bash
python3 backend/server.py --port 8768 --db output/local/tasks.db --ask-feishu
```

输入飞书 App ID 与 App Secret（隐藏输入）。不使用飞书可省略 --ask-feishu。
打开 http://127.0.0.1:8768/ ，在“切换 API”填写服务地址、模型和密钥，重启后需重填。
产品页：http://127.0.0.1:8768/landing.html 。
音频识别仍需安装原项目依赖和 small 模型；未包含模型和环境。仅文字/飞书导入无需音频模型。
